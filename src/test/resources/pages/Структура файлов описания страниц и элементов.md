В этой директории находятся yaml-файлы с описанием страниц. 
Содержимое директории можно структурировать с помощью каталогов. Глубина вложений не ограничена.
<br>
<h3>Структура файла:</h3>
<table>
<tr><td><b>Название:</b></td><td>Название страницы, которое будет фигурировать в сценариях</td></tr>
<tr><td><b>Элементы:</b></td><td>Структурный блок с описанием элементов страницы</td></tr>
<tr><td><b>Обязательные элементы:</b></td><td>Список элементов, отображение которых свидетельствует об окончании загрузки страницы</td></tr>
<tr><td><b>Общие блоки элементов:</b></td><td>Список элементов, описанных в файлах из директории pageFragments. Элементы общих блоков дописываются в список элементов страницы. Надо контролировать, чтобы названия корневых элементов страницы не совпадали с названиями элементов общих блоков</td></tr>
<tr><td><b>Максимальное время ожидания:</b></td><td>Время ожидания загрузки страницы. Может принимать значения: 
    <ul><li><i>по умолчанию</i> - время ожидания определяется настройкой <i>pageLoadingTimeout</i></li>
    <li><i>n секунд|минут[а|ы]</i>, где n - целое число</li></ul></td></tr>
</table>

<h3>Структура описания элемента:</h3>
Элемент должен быть описан парой <i><Название></i>: <i><локатор></i>, в случае, если он простой 
и для взаимодействия с ним достаточно одного локатора. Например, поле ввода, кнопка или ссылка.
В качестве локатора может быть указано значение атрибута <i>data-id</i> или xpath. 
<p><strong>Важно! Все xpath в локаторах должны быть абсолютными, т.е. начинаться с //</strong></p>

Для сложных элементов требуется структурное описание
<table>
<tr><td colspan="2"><i>Название элемента, которое будет фигурировать в сценариях</i>:</td></tr>
<tr><td>&nbsp;&nbsp;<b>тип:</b></td><td>тип элемента, определяющий класс и методы реализации интерфейса. 
    Типы элементов прописаны в yaml-файле src/test/resources/элементы/элементы.yaml</td></tr>
<tr><td>&nbsp;&nbsp;<b><метод поиска: xpath, test-id>:</b></td><td>селектор, по которому веб-драйвер с помощью указанного метода будет искать элемент</td></tr>
<tr><td>&nbsp;&nbsp;<b>...:</b></td><td>Далее структура описания элемента зависит от его типа</td></tr>
</table>
