Структура описания типов элементов представляет собой словарь, где в качестве ключа выступает название типа, а значением является набор полей, описывающих тип.
Обязательным полем является поле <b>класс</b>, значением которого должна быть ссылка на класс элемента.
Необходимость указания других полей определяются классом элемента.

<h3>Сложные или блочные типы элементов</h3>
Такие элементы являются контейнерами, содержащими в себе другие элементы любых типов. 
Это позволяет реализовывать сложную логику, сводя её к простым шагам.
Локатор элемента, заданный с помощью xpath или test-id, должен указывать на родительский элемент по отношению к вложенным.
Вложенные элементы описываются в значении поля <i>элементы</i> в том же виде, как при описании элементов страницы.
Глубина вложенности элементов не ограничена.

При описании типа элемента можно задать значения xpath или test-id по умолчанию. В большинстве случаев локаторы вложенных элементов одинаковы, поэтому нет необходимости их описывать для каждого элемента и страницы.
Для частных случаев в описании конкретного элемента на странице можно указать эти значения, чтобы переопределить значения по умолчанию.
