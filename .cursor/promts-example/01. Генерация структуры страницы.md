Для выполнения генерации описания структуры html-страницы с использованием IDE Cursor AI необходимо предварительно
подготовить набор из html-файлов, показывающих разные возможные состояния страницы (видимы разные наборы полей; видимы
списки в комбобоксах; и т.д.). Сбор подобных файлов можно выполнить, например, используя сохранение страницы в браузере.
Для сохранения всё текущей dom-модели страницы необходимо при сохранении выбирать тип файла "Веб-страница, полностью".

Не всегда с первого раза может получиться требующийся результат. Для этого можно выполнять в том же чате дополнительные
команды на доработку.
Например:
```
КРИТИЧЕСКИ ВАЖНО, чтобы генерируемый файл был похож по структуре на пример из файла "instructions/Пример файла с описанием страницы.yaml"
и другие файлы, такие как src/test/resources/pages/НСО.yaml, src/test/resources/pages/Главная.yaml. Переделай.
```
, или
```
Сделай группировку элеменов по контейнерам. Примеры контейнеров: "50 Приказодатель Ordering Customer" (включает
элементы "Наименование организации", "ИНН/КИО", "Счёт списания", "Валюта списания"), "Адрес" (включает элементы "Улица дом",
"Страна регистрации город область"), и т.д.
```
, или
```
Попробуй вместо xpath вида //input[@id=':rb0:'] использовать другие селекторы, так как id вида ":значение:" изменяются при генерации страницы.
```
